# Matthew Lestermun — портфолио

Сайт-портфолио с 3D-логотипом из кубиков и интерактивными карточками проектов.

## Что внутри

- 3D-логотип **ML_** на Three.js: собирается при загрузке, следит за мышкой, разлетается при прокрутке
- Карточки проектов с 3D-наклоном и бликом за курсором
- Меню на весь экран, живые часы, бегущая строка
- Этапы работы, цены, счётчик челленджа «90 дней, 0 → $1000»
- Адаптив под телефон

## Проекты

- [FORMA](https://matthewlestermun.github.io/forma-fitness/) — фитнес-студия
- [Зерно](https://matthewlestermun.github.io/zerno-coffee/) — кофейня-пекарня

## Технологии и безопасность

Чистые HTML, CSS и JavaScript. Three.js лежит в проекте локально (сверен с официальной контрольной суммой),
на странице включена Content Security Policy — посторонние скрипты браузер не выполнит.
